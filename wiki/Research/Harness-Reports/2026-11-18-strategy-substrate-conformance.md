# Strategy substrate conformance audit (2026-11-18)

**Question.** The owner ran strategies in Cortex on 2026-11-18 (21:36 to 22:12 local) and saw reflexion, direct, code-action and tree-of-thought reason worse than reactive. Is that a model effect, or do these strategies get less from the shared substrate than reactive does?

**Answer.** It is the harness, not reasoning quality. Every failing run traces to one of five substrate gaps. None of them is the model reasoning badly with the same inputs:

1. **Reflexion, tree-of-thought and plan-execute step kernels drop the run's model facet.** Each one hand-builds its kernel input without `providerName` or `contextProfile`. Their passes ship `provider: unknown` and a 2,000-token think budget instead of 8,000 (no frontier tier, no thinking allowance), and they project against a 32,768-token window instead of 1,000,000 (gemini-2.5-flash).
2. **A strategy body error skips the one terminal.** `runStrategy` catches only `StrategyPaused`. All 4 code-action failures and 2 reflexion failures ended as raw `ExecutionError`s with no `terminal_decision`, no outcome and no evidence attached.
3. **Reflexion's pass structure fights the substrate's worst-of law.** Superseded failed passes cap a later verified answer, and the 16-iteration budget is split 4 ways, so the generate pass cannot finish a 5-tool task.
4. **code-action refuses too broadly.** It refuses any approval policy whose `tools` set is non-empty, and the runtime fills that set with every registered `requiresApproval` tool. So Cortex's default policy refuses code-action even when every callable tool is read-only. All 4 code-action runs spent 0 tokens.
5. **Budgets were not inherited** (direct capped at 1, ToT at its tier table's 8). An uncommitted change already in the working tree fixes this, except for reflexion's per-pass split.

The meta-tool tax (`todo` takes about 50% of tool calls, reactive included) is shared. It hurts most where the per-pass budget is small.

**Cost.** Zero tokens. No live-model runs. One zero-token scripted probe. Analysis used `rax-diagnose cause/attribute` plus reading the raw JSONL.
