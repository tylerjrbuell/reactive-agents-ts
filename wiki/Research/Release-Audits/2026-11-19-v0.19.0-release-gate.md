## Blockers

### B1: `console.warn` ceiling breached (13 sites, ceiling 12)

- **Test:** `packages/observability/tests/console-ceiling.test.ts:233` — `WS-5 Phase 3 — console.* ceiling > console.warn sites stay ≤ 12 across runtime + reasoning + RI + memory`
- **Error:** `Found 13 console.warn call sites (ceiling: 12).`
- **Cause:** `683c0debe` ("fix(runtime): off-TTY warnings go to stderr…", 2026-11-17) added a new site at `packages/runtime/src/engine/execute-obs-wiring.ts:163` inside `makeExecutionLogger`: `Effect.sync(() => { console.warn(`${prefix}${formatted}`); })`. It is a deliberate stderr sink for live warnings. The ratchet was not raised, and the site has no rationale comment. The test's own message names both fixes.
- **Fix (pick one):** (a) raise `WARN_CEILING` from 12 to 13 with a dated rationale, and add the one-line rationale comment at the new site that points at `packages/core/src/errors/index.ts`. (b) Write the line with `process.stderr.write`, so the sink is not a `console.*` call.
- **Owners:** `runtime-warden` (the site). `core-warden` is co-owner per `bun run repo scope` on the test.
- **Blocks release:** yes. publish.yml runs the test suite before it publishes, so the tag would fail there.

### B2: `resolveOllamaEndpoint` default test fails under the CI mirror (blocks the push, not publish)

- **Test:** `packages/llm-provider/src/ollama-endpoint.test.ts:22` — `resolveOllamaEndpoint > defaults to localhost`
- **Error:** `Expected: "http://localhost:11434"` / `Received: "http://127.0.0.1:9"`
- **Cause:** `bun run repo ci` sets `OLLAMA_HOST=http://127.0.0.1:9` (`tools/repo/src/commands/ci.ts:20,53`, added in `2707d04fe` on 2026-11-17) to make Ollama unreachable. The test clears `OLLAMA_ENDPOINT` / `OLLAMA_HOST` / `OLLAMA_BASE` only in `afterEach`, so the first test sees the host value. `.github/workflows/ci.yml` and `publish.yml` set no `OLLAMA_*` variable, so remote CI and publish.yml should pass this test. The test also fails for any developer who has `OLLAMA_HOST` set in their shell.
- **Why it still blocks:** `.githooks/pre-push` runs `bun run repo ci`. The hook will refuse both `git push origin dev` and `git push origin main` until the mirror passes. `--no-verify` bypasses it, but the bypass is logged.
- **Fix:** in the test, clear the three variables in a `beforeEach` too (save and restore the host values). Owner: `provider-warden`. Alternative or extra: `tooling-warden` stops the mirror's Ollama sentinel from leaking into unit tests that assert defaults.
