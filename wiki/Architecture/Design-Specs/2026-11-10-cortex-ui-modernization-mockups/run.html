A hash function is a one-way mathematical function that maps data of any size to a fixed-size output, called a hash or digest, while making it computationally infeasible to reverse the process or find two different inputs that produce the same output. This property makes hashes ideal for integrity checks: changing one bit of the input changes the digest completely.
