<Aside type="tip" title="Bun recommended — Node.js 22.5+ also supported">
Bun ≥1.1.0 gives optimal performance (native SQLite, subprocess, HTTP). **Node.js 22.5+** is fully supported via `@reactive-agents/runtime-shim` — use `npm install reactive-agents` or `npx tsx` if you prefer the Node.js ecosystem. Install Bun: `curl -fsSL https://bun.sh/install | bash`.
</Aside>

## From zero to running agent

<ol class="ra-steps">

<li>

**Install the meta-package.**

```bash
# Bun (recommended)
bun add reactive-agents

# Node.js 22.5+
npm install reactive-agents
npm pkg set type=module   # examples use top-level await
```

Prefer a ready project? `npm create reactive-agent my-agent` scaffolds one, including an `AGENTS.md` that points coding agents (Claude Code, Cursor, Codex) at the current docs. See [create-reactive-agent](/features/create-reactive-agent/).

</li>

<li>

**Set at least one provider key** in `.env` (or skip if you're going local).

```bash
touch .env
# then add one line with your real key, for example: ANTHROPIC_API_KEY=<your key>
# or OPENAI_API_KEY, GOOGLE_API_KEY, GROQ_API_KEY, XAI_API_KEY, LITELLM_API_KEY
# Scaffolded with `rax init`? Run `cp .env.example .env` and replace the
# `your-key-here` placeholder instead (an unedited placeholder counts as a missing key).

# No key? Run fully local with Ollama instead:
ollama pull qwen3:4b
```

Going local, swap the provider in step 3: `.withProvider("ollama").withModel("qwen3:4b")`
on the builder (or `provider: "ollama", model: "qwen3:4b"` in the config) — no key required. See the [Local Models guide](/guides/local-models/).

</li>

<li>

**Build your first agent** — three lines is enough.

<Tabs syncKey="syntax">
  <TabItem label="Declarative">
```typescript
import { createAgent } from "reactive-agents";
const agent = await createAgent({ name: "my-agent", provider: "anthropic" });
console.log((await agent.run("Hello")).output);
```
  </TabItem>
  <TabItem label="Builder">
```typescript
import { ReactiveAgents } from "reactive-agents";
const agent = await ReactiveAgents.create().withProvider("anthropic").build();
console.log((await agent.run("Hello")).output);
```
  </TabItem>
</Tabs>

</li>

<li>

**Run it.**

```bash
# Bun
bun run src/agent.ts

# Node.js (requires tsx; Node does not load .env on its own, so pass it)
npx tsx --env-file=.env src/agent.ts
```

</li>

</ol>

## Simple Install

The easiest way to get started is with the `reactive-agents` meta-package, which bundles everything:

<Tabs syncKey="pkg">
  <TabItem label="bun">
  ```bash
  bun add reactive-agents
  ```
  </TabItem>
  <TabItem label="npm">
  ```bash
  npm install reactive-agents
  ```
  </TabItem>
  <TabItem label="pnpm">
  ```bash
  pnpm add reactive-agents
  ```
  </TabItem>
  <TabItem label="yarn">
  ```bash
  yarn add reactive-agents
  ```
  </TabItem>
</Tabs>

:::note[Effect dependency]
`reactive-agents` declares `effect` as a **peer dependency** (`"effect": "^3.10.0"`) and `@reactive-agents/core` additionally carries it as a regular dependency — so `effect` lands in your install tree via the framework; declare it yourself (`bun add effect`) if you import from it directly. When you write hooks, tools, or tests, import helpers explicitly — e.g. `import { Effect } from "effect"` — then use **`Effect.succeed`**, **`Effect.fail`**, **`Effect.gen`**, **`Effect.runPromise`**, etc. See the [Effect-TS primer](/concepts/effect-ts/) for a cheat sheet.
:::

Then import from a single entry point (`ReactiveAgents` for the builder, `createAgent` for the declarative config):

```typescript
import { ReactiveAgents } from "reactive-agents";
```

## Modular Install

The framework is modular — install only the packages you need:

**Foundation (required)**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/core`          | EventBus, AgentService, TaskService, canonical types                      |
| `@reactive-agents/runtime`       | {metrics.phases}-phase ExecutionEngine, ReactiveAgentBuilder, `createRuntime()` |
| `@reactive-agents/llm-provider`  | LLM adapters: Anthropic, OpenAI, Gemini, Groq, xAI, Ollama, LiteLLM, Test |
| `@reactive-agents/runtime-shim`  | Cross-runtime primitives (Bun or Node.js 22.5+): Database, spawn, serve   |

**Cognition (recommended)**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/reasoning`     | {metrics.strategies} strategies (ReAct, Blueprint, Plan-Execute, Reflexion, ToT, Adaptive, Direct, Code-Action, experimental) + composable kernel |
| `@reactive-agents/memory`        | 4-layer memory (working, semantic, episodic, procedural) on SQLite (`bun:sqlite` or `node:sqlite`) |
| `@reactive-agents/tools`         | Tool registry, sandbox, MCP client, healing pipeline                      |
| `@reactive-agents/prompts`       | Template engine, version-controlled prompt library                        |
| `@reactive-agents/reactive-intelligence` | Entropy sensor, reactive controller, learning engine, opt-in telemetry |
| `@reactive-agents/judgment`      | Typed judgment questions (yes/no, choice, score) with probabilities, over pluggable backends. Experimental |

**Production safety**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/guardrails`    | Injection, PII, toxicity detection, kill switch                           |
| `@reactive-agents/verification`  | Semantic entropy, fact decomposition, NLI hallucination detection         |
| `@reactive-agents/cost`          | Multi-factor complexity routing, budget enforcement, semantic cache       |
| `@reactive-agents/identity`      | Ed25519 agent certificates, RBAC, delegation, audit                       |
| `@reactive-agents/compose`       | Prebuilt killswitches: `maxIterations`, `budgetLimit`, `timeoutAfter`, `watchdog`, `requireApprovalFor` |
| `@reactive-agents/health`        | Health checks and readiness probes                                        |

**Observability and replay**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/observability` | OTLP tracing, MetricsCollector, structured logging                        |
| `@reactive-agents/trace`         | Structured execution trace recording and inspection                       |
| `@reactive-agents/observe`       | OpenTelemetry/OpenInference tracing to any OTLP backend                   |
| `@reactive-agents/replay`        | Deterministic re-run of recorded traces with prompt or model overrides    |
| `@reactive-agents/diagnose`      | `rax-diagnose` CLI: replay, grep, diff, and debrief recorded runs         |

**Composition & multi-agent**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/a2a`           | Agent-to-Agent protocol: Agent Cards, JSON-RPC 2.0, SSE streaming         |
| `@reactive-agents/gateway`       | Persistent autonomous harness: heartbeats, crons, webhooks, policy engine |
| `@reactive-agents/channels`      | Channel routing for the gateway: route validation, per-sender access, SQLite route store |
| `@reactive-agents/interaction`   | 5 autonomy modes, checkpoints, preference learning                        |

**Evaluation & testing**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/eval`          | Evaluation suites, LLM-as-judge scoring, `EvalStore` (SQLite)             |
| `@reactive-agents/testing`       | Mock `LLMService` / `ToolService` / `EventBus`, assertion helpers (dev)   |

**Frontend integration**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `@reactive-agents/react`         | React 18+ hooks and components: `useAgentStream`, `useAgent`, `useRun`, `ApprovalGate` |
| `@reactive-agents/vue`           | Vue 3 composables: `useAgentStream`, `useAgent` with reactive refs        |
| `@reactive-agents/svelte`        | Svelte 4/5 stores: `createAgentStream`, `createAgent`, `createRun`        |
| `@reactive-agents/ui-core`       | Headless core the UI bindings share: run stream client, run state, UI tree types |

**Developer tooling**

| Package                          | Description                                                               |
| -------------------------------- | ------------------------------------------------------------------------- |
| `create-reactive-agent`          | Project scaffolder: `npm create reactive-agent` (also used by `rax init`); writes `AGENTS.md` for coding agents |
| `@reactive-agents/cortex`        | Cortex Studio, a local UI for inspecting runs. Start it with `rax cortex` (needs Bun) |

## Environment Variables

Create a `.env` file:

```bash
# LLM Provider — set at least one
ANTHROPIC_API_KEY=sk-ant-...        # Anthropic Claude
OPENAI_API_KEY=sk-...               # OpenAI GPT-4o
GOOGLE_API_KEY=...                  # Google Gemini
GROQ_API_KEY=gsk_...                # Groq
XAI_API_KEY=xai-...                 # xAI Grok
LITELLM_API_KEY=...                 # Optional — LiteLLM proxy auth when required

# Tools (optional)
TAVILY_API_KEY=tvly-...             # Enables built-in web search tool (any one search key works; see Tools)
# KEENABLE_API_KEY=...              # Alternative search key (also: SERPER_API_KEY, BRAVE_SEARCH_API_KEY)

# Embeddings (for enhanced / `"2"` memory tier — vector semantic search)
EMBEDDING_PROVIDER=openai           # "openai" | "ollama"
EMBEDDING_MODEL=text-embedding-3-small

```

Tuning variables (`LLM_DEFAULT_MODEL`, `LLM_DEFAULT_TEMPERATURE`, `LLM_MAX_RETRIES`, `LLM_TIMEOUT_MS`) and every default are listed in [Configuration: environment variables](/reference/configuration/#environment-variables).

## TypeScript Configuration

Reactive Agents requires TypeScript 5.5+ with strict mode. This is the minimum config:

```json title="tsconfig.json (required)"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true
  }
}
```

Two stricter flags are **recommended** for new projects — but they tighten checks across your whole codebase, so enabling them in an existing project may require code changes beyond Reactive Agents:

```json title="tsconfig.json (recommended additions)"
{
  "compilerOptions": {
    "exactOptionalPropertyTypes": true,
    "noUncheckedIndexedAccess": true
  }
}
```
